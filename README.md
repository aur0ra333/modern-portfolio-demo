# 申浩天个人作品集

用于集中展示在线项目、技术栈和联系方式的静态作品集页面。

## 在线演示

[访问作品集](https://aur0ra333.github.io/modern-portfolio-demo/)

## 项目分层

- 主项目：Markdown 文档工作台、运营数据看板
- 工具项目：任务看板、城市天气观察台
- 内容展示：个人技术博客
- 产品原型：任务协作实验室

## 页面内容

- 个人简介：计算机科学与技术本科，关注 Web 前端、Java 后端和数据库设计
- 技术栈：Vue / React、JavaScript、Spring Boot、MySQL、Redis、Git、Maven、Postman 等
- 在线项目：统一展示 6 个可访问项目，并提供 GitHub 链接
- 联系方式：邮箱和 GitHub

## 技术实现

- HTML5 语义化结构
- CSS3：Grid、Flexbox、响应式布局、CSS 变量
- JavaScript：滚动定位、项目筛选、主题切换、表单演示
- GitHub Pages 部署

## 本地运行

```bash
git clone https://github.com/aur0ra333/modern-portfolio-demo.git
cd modern-portfolio-demo
python -m http.server 8080
```

然后访问 `http://localhost:8080`。
